# MiriTranslator — release channel

가벼운 브라우저 만화 번역기 — 로컬 지우기·조판 + 무료 API, 서버 불필요, 모바일 지원.
Lightweight in-browser manga translator — local erase & typesetting plus free APIs, no server required. Works on mobile.

**설치 / Install:** [MiriTranslator.user.js](https://raw.githubusercontent.com/enflip/MiriTranslator-release/main/MiriTranslator.user.js)
(Violentmonkey / Tampermonkey 가 설치 창을 띄웁니다. 이후 업데이트는 자동.)

현재 버전 / current version: **0.3.0**

이 저장소에는 빌드된 스크립트만 올라옵니다. This repository only carries the built script.
